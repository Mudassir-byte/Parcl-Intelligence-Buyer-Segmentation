The headline finding

The brief proposed four buyer personas. The data supports three groups instead: a small, genuinely distinct high-frequency repeat-buyer segment (2.65% of clients), and the remaining 97% split almost entirely by recorded satisfaction, not by geography, financing, or acquisition purpose. See Segmentation for the evidence and Notices & Limits for what that means in practice.

Notices & limitations

Read this before presenting any number on this page externally.

Engagement is a proxy. No clickstream or saved-search data exists in the source files. engagement_score is built from satisfaction + purchase frequency, not measured digital behavior.
Not a targeting model. Cluster membership reflects statistical similarity at one point in time - never use it as the sole basis for a lending, pricing, or legal decision.
Small segment, wider uncertainty. Cluster 0 is 53 clients. Its centroid is real but less stable than the two ~950-1,000-client clusters - re-validate before high-stakes use.

Full documentation - methodology, data dictionary, evaluation report, and ethics review - lives in the reports/ folder of the project repository this dashboard was generated from.

Parcl Buyer Segmentation Dashboard - built from clients.csv (2,000 rows) and properties.csv (10,000 rows). No fabricated data, results, or links. Model version -, trained with a fixed random seed (42) for reproducibility.
